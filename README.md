# 🕹️ Cyber Arcade Mobile - 3-in-1 Retro Arcade Game Center

Ek shandar, modern retro arcade game jo mobile aur desktop dono ke liye optimized hai. Isme 3 games shamil hain:

1. 🚀 **Galaxy Strike (Space Shooter)**:
   - Spaceship combat, enemy waves, dynamic boss fights.
   - Power-ups: Triple Laser, Spread Shot, Hyper Laser, Plasma Shield, Extra Life, Nuke Bomb.
   - Screen shake, particle explosions, dynamic audio synthesizer.
2. 🐍 **Cyber Snake**:
   - Neon glowing snake with swipe gestures and virtual D-Pad.
   - Normal Food, Golden Bonus Star, speed acceleration, score records.
3. 🧱 **Brick Breaker DX**:
   - Touch drag paddle physics, multi-ball split powerups, explosive bricks, dynamic bouncing.

---

## 📱 Kaise Khelein (How to Play)

### 1. Browser / Mobile Par Chalana:
Terminal / Command Prompt me run karein:
```bash
python server.py
```
- Browser me automatically `http://localhost:8080` open ho jayega.
- Agar apne **Android Mobile** par khelna chahte hain to apne mobile browser (Chrome/Safari) me terminal me show hone wala IP URL kholein (e.g. `http://192.168.x.x:8080`).

### 2. Android Studio Project (.APK banana):
- Folder: `android-project/`
- Android Studio me **"Open an Existing Project"** par click karein aur `android-project` folder select karein.
- **Run** ya **Build > Build Bundle(s) / APK(s) > Build APK(s)** karein.

---

## 🎮 Controls:
- **Mobile Touch Controls**:
  - Screen par direct drag / swipe karein.
  - Virtual On-Screen D-Pad (▲ ▼ ◀ ▶).
  - 💣 **NUKE Button**: Screen par mojood sab dushmano ko khatam karein.
- **Keyboard Controls (PC)**:
  - `Arrow Keys` / `W, A, S, D`: Movement / Direction
  - `Space` ya `B`: Nuke Bomb / Ball launch
  - `P`: Pause / Resume
